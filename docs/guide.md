# DTBO Studio 新手教程：刷新率超频与温控表修改

这份教程面向第一次接触 DTBO 的用户，从零开始讲两件事：

- **刷新率超频**：给屏幕加一个更高的刷新率档位（例如 120 Hz → 144 Hz）。
- **修改温控表**：调整手机发热时的充电限流，让它在温度升高后不那么早降速。

> ⚠️ **先读这一段再动手**
>
> DTBO 是手机开机时加载的硬件配置。改错了可能**黑屏、花屏、无法开机**，温控改得过激可能让电池**过热、加速老化**。
> 本教程每一步都会告诉你怎么留后路，请不要跳过“备份”和“救砖”两节。所有后果由操作者自行承担。

## 1. 准备工作

| 项目 | 必需？ | 说明 |
| --- | --- | --- |
| Bootloader 已解锁 | 必需 | 未解锁无法刷入修改后的 DTBO |
| Root（KernelSU / Magisk / APatch） | 推荐 | 有 Root 才能在手机上直接提取和刷入；没有 Root 也能用，但需要自己提供 `dtbo.img` 并用电脑刷 |
| 电脑 + Fastboot 环境 | 强烈推荐 | 万一不开机，要靠它刷回原版 |
| 原版 `dtbo.img` 备份 | 必需 | 本应用直刷前会自动备份，但建议你自己再存一份到电脑 |
| 电量 50% 以上 | 必需 | 刷写过程中断电会很麻烦 |

**第一次打开应用**会弹出免责声明，倒计时结束后点「同意并继续」。有 Root 的话，按提示授予 Root 权限。

## 2. 认识界面

底部有 4 个标签页：

| 标签 | 作用 |
| --- | --- |
| **概览** | 导入镜像、查看解析结果、打包、导出、刷入，都在这里 |
| **功能模块** | 「刷新率」和「Charging」（充电/温控）两个编辑面板 |
| **设备树** | 高级用户直接改属性用，新手不需要碰 |
| **设置** | Root 状态、槽位信息、备份与恢复、关于 |

右上角两个按钮：🕘「备份与恢复」、🔄「刷新环境」。

**核心概念——“暂存 → 打包 → 刷入”**

你在功能模块里做的每一次修改，都不会立刻写入手机，而是先**暂存**成一条“事务”。所有修改做完后，回到「概览」**集中打包**生成新镜像，最后再决定**导出**还是**刷入**。暂存之后随时可以撤销，不用担心点错。

## 3. 第一步：导入 DTBO

进入「概览」→「镜像来源」卡片：

- **有 Root**：点「**提取当前分区**」。应用会读取当前槽位的 DTBO，并自动识别**本机正在用的屏幕**和**本机生效的 DTB**。✅ 推荐这种方式。
- **没有 Root**：点「**手动导入**」，选择你从官方刷机包里解出来、或从别处获取的 `dtbo.img`。
  这种方式无法自动识别在用屏幕，后面需要你自己判断。

导入完成后会出现「镜像解析结果」卡片，重点看：

- **唯一面板 / 时序候选**：识别到几块屏幕、几个刷新率档位。
- **在用：xxx**（绿色标签）：这就是你手机正在用的屏幕，后面要改的就是它。
- **AVB 状态**：无需处理，打包时会自动更新校验信息。

## 4. 刷新率超频

### 4.1 打开刷新率面板

「功能模块」→ 点「**刷新率**」卡片，下方展开「参数微调与超频推演」。

### 4.2 选对屏幕和档位（最重要的一步）

面板顶部是档位选择器：

1. **筛选**：默认选中「本机在用」，只显示你手机的屏幕。没有 Root 导入时可选「厂商面板」，或用搜索框搜屏幕型号。
2. **选择 DTB 实例**：同一块屏幕往往在多个 DTB 里各有一份，但开机只会加载其中一个。
   **一定要选带「本机生效」字样的那个**，改其他的不会生效。
3. **选择原始档位**：列出这块屏幕现有的刷新率档位，例如 `60Hz / 90Hz / 120Hz`。
   - ✅ 选名字里带 `normal` 的**普通档位**，并且选**最高的那个**作为基础（比如想加 144 Hz，就选 120 Hz 档）。
   - ❌ 带「**自动变频 / idle**」标记的（如 `auto_120_to_30hz`）**不要选**，改它容易黑屏或卡开机，应用也会直接禁止操作。
   - 如果看到「**非量产屏节点，改后不生效**」，说明这是高通参考屏，不是你的屏幕，换一个。

### 4.3 选择操作模式

| 模式 | 效果 | 适合谁 |
| --- | --- | --- |
| **新增独立档位** | 保留原档位，额外复制出一个新刷新率档位 | ✅ 新手首选，原来的 120 Hz 不受影响 |
| **编辑修改档位** | 直接把原档位改成新刷新率（原档位消失） | 系统不认新增档位时再用 |
| **删除指定档位** | 删掉一个档位 | 一般用不到；每块屏幕至少会保留 1 个档位 |

### 4.4 设置目标刷新率

在「目标刷新率」区域，可以点**快捷预设**（例如 `135 Hz`、`144 Hz`），也可以拖滑块或直接输入数字。

**建议循序渐进**：第一次只加 10～15 Hz（例如 120 → 130/135），能正常开机、显示正常再往上加。一口气拉太高，屏幕很可能不支持。

### 4.5 选择计算策略

| 策略 | 说明 | 建议 |
| --- | --- | --- |
| **平衡时序** | 同时调整时钟和消隐参数，兼容性最好 | ✅ 默认就用这个 |
| **仅 Pixel Clock** | 只按比例提高时钟 | 平衡时序不生效时可以试 |
| **仅 Framerate** | 只改刷新率数字，不改时钟 | ❌ 不建议，基本不会真正提升刷新率 |
| **自定义** | 手动填时钟、VFP/VBP/HFP/HBP | 懂 DSI 时序的高级用户 |

### 4.6 看一眼推演结果

「**超频效果实时推演**」卡片会显示：

- 刷新率变化，例如 `120 Hz → 144 Hz`
- **预估 Pixel Clock** 以及倍率（如 `×1.20`）
- 消隐行数的变化（VFP / VBP）

倍率越高，对屏幕的压力越大。一般 ×1.1～×1.2 以内相对稳妥。

### 4.7 暂存

点底部按钮：

- 新增模式：「**追加为此面板新档位 (暂存)**」
- 编辑模式：「**应用修改到当前时序 (暂存)**」

提示“已暂存修改”后，就可以去 [第 6 节](#6-打包与刷入) 打包了。如果还想改温控表，可以先继续做完第 5 节，最后一起打包。

## 5. 修改温控表

### 5.1 温控表是什么

手机充电时会根据温度分成若干**档位**：温度低时是第 1 档，限流最宽松；温度越高，档位越高，**允许的充电电流越小**。
修改温控表，就是调整“在每个温度档位最多允许多少电流”。

> 注意：这里改的是**发热后的限流**，不是充电器功率，也不是充电芯片的最高电流。把第 1 档调高，并不能让 67 W 的手机变成 120 W。

### 5.2 打开 Charging 面板

「功能模块」→ 点「**Charging**」卡片，下方展开「Charging 参数编辑」。

- 如果提示“**当前 DTBO 未发现充电参数**”，说明你的机型把充电配置放在别的分区（如 vendor_boot），本应用无法修改，到此为止。
- 顶部统计会显示“X 个可编辑参数 · X 个可编辑节点”。

### 5.3 找到温控表

1. 如果当前节点带温控表，会出现按钮「**转到温控表：DTB x · xxx**」，点它直接跳过去。
2. 或者点「**切换充电节点（N）**」，在列表里找标有「**含温控表**」的节点。
3. 和刷新率一样，同一节点可能出现在多个 DTB 里，优先改**本机生效**的那个 DTB。

目前能识别的温控表：

| 机型/平台 | 表名 | 结构 |
| --- | --- | --- |
| 高通通用（QTI battery charger） | 充电温控限流 `qcom,thermal-mitigation` | 一列，若干档，例如 `3000 / 1500 / 1000 / 500 mA` |
| 小米 MCA | 有线温控 `wired_thermal` | 每档 10 列：5 V 输入、9 V 输入、5 V 充电、9 V 充电、DIV1/DIV2/DIV4 单路/多路 |
| 小米 MCA | 无线温控 `wireless_thermal` | 每档 10 列：BPP 输入、BPP QC2/QC3、EPP 输入、CP 20/30/50/80 W、音箱、磁吸 30 W |

### 5.4 编辑表格

温控表以表格形式显示：**每一行是一个档位，每一列是一个通道**，单位是 mA。表格可以左右滑动查看所有列。

- **直接点单元格改数字**。改过的格子下方会显示“原 xxxx”，方便对比。
- **红框**表示数字无效，或者**比上一档还大**。规则是：同一列里，下一档不能高于上一档（温度更高时电流只能更小或相等）。最后一档可以是 0。
- **联动相同通道**（开关）：如果几列的原始数值完全一样，默认会合并成一列一起改，省得一个个填。想单独改某一列就关掉它。
- **恢复本表原值**：改乱了一键还原。

### 5.5 批量调整（推荐新手用）

点「**批量调整（按百分比）**」：

1. **选择通道**：勾选要调整的列（例如「9 V 充电」）。
2. **从第几档 / 到第几档**：例如 `2` 到 `5`。
3. **调整 %**：`+10` 表示上调 10%，`-20` 表示下调 20%。
4. 点「**应用到表格**」。

结果会按 10 mA 取整；如果调整后超过了上一档，会被自动截断到和上一档相同，并提示有几个格子被截断。

**建议**：
- 只调整**中间几档**，第 1 档（最宽松）和最后几档（高温保护）尽量别动。
- 单次上调不超过 **10%～20%**，实际使用一段时间观察温度再决定是否继续。
- 夏天、边充边玩游戏的场景，本来就是温控在保护电池，不要为了快而把高温档拉满。

### 5.6 暂存

1. 在「**修改预览**」里确认改动内容，没有红色报错。
2. 点「**暂存充电修改**」。
3. 看到“此节点已暂存 N 次修改”就成功了。

改错了没暂存：点「**重置未暂存输入**」。已经暂存了：到「概览」点「撤销最近事务」。

## 6. 打包与刷入

### 6.1 集中打包

回到「**概览**」，会看到「**设备树事务 · N 个**」卡片，列出你暂存的所有修改：

- 「**集中打包**」：把所有修改编译成新的 DTBO 镜像。
- 「撤销最近事务」：撤回最后一次修改。
- 「全部重置」：放弃所有修改，回到原始镜像。

点「集中打包」，等待完成。应用会自动校验：只有你改的地方变了，其余属性一个字节都没动。

### 6.2 选择输出方式

打包成功后出现「**输出**」卡片，按推荐顺序：

| 方式 | 说明 | 推荐度 |
| --- | --- | --- |
| **制作成模块并刷入** | 以 KernelSU / Magisk / APatch 模块安装。**在管理器里移除模块并重启，就自动恢复原 DTBO** | ⭐⭐⭐ 新手最推荐，反悔最方便 |
| **导出 KernelSU / Magisk 模块** | 只生成模块 zip，自己到管理器里安装 | ⭐⭐⭐ |
| **直接刷写当前槽位** | 直接写入分区。刷之前自动备份并生成救援包 | ⭐⭐ |
| **导出 PC Fastboot 一键包** | 在电脑上用 Fastboot 刷 | ⭐⭐ 没有 Root 时用 |
| **导出 Recovery 刷机 Zip** | 在第三方 Recovery 里刷 | ⭐⭐ |
| **保存 dtbo_patched.img** | 只保存镜像文件，自己处理 | 高级用户 |

### 6.3 刷入确认

选择刷入后会弹出「**高危操作：写入物理 DTBO 分区**」对话框：

1. 核对“目标”分区路径。
2. 在输入框里输入**目标刷新率数字**（如 `144`），或者输入大写 `FLASH`。
3. 等待 5 秒倒计时结束，点「确认以模块刷入」或「确认单槽位刷写」。

刷入完成后会显示「**救砖备忘录**」卡片，**请务必立刻做这两件事**：

- 点「**导出备份**」和「**导出救援包**」，把文件存到手机存储并**复制到电脑**。
- 点「**截图保存备忘录**」，记下分区名和 SHA-256。

然后重启手机。

## 7. 刷入后检查

### 刷新率

1. 到系统「设置 → 显示 → 刷新率」看是否出现新档位（有些系统不会列出新增档位，可以用第三方刷新率切换工具）。
2. 打开开发者选项里的“显示刷新率”，或用帧率测试工具/网站（如 testufo）确认**实际**刷新率。
3. 观察几分钟：有没有闪屏、花屏、横条纹、颜色异常。有任何异常，**立即恢复**（见第 8 节）。

> 部分屏幕是**命令模式屏**，刷新率由屏幕芯片里的指令决定。这类屏幕只改时序，数字变了但实际帧率不变，属于正常现象，换策略也没用。

## 8. 救砖与恢复

按情况从轻到重：

**① 能开机，只是效果不满意**
- 模块方式刷入的：到 KernelSU / Magisk / APatch 管理器里**移除模块并重启**。模块是在这次开机过程中把原 DTBO 写回去的，所以要**再重启一次**才能看到原样。
- 直接刷写的：顶部「备份与恢复」→ 选择刷入前的备份 → 「**刷入**」→ 确认后重启。可以先点「验证 MD5」确认备份完好。

**② 屏幕黑了 / 花屏，但系统其实开机了**
- 模块方式刷入、且电脑能连上 adb 的话，给模块打上移除标记后重启，模块卸载时会写回原 DTBO：

  ```bash
  adb shell su -c "touch /data/adb/modules/dtbo_refresh_overclocker/remove"
  adb reboot
  ```

  同样需要开机后**再重启一次**才会恢复原样。

- 大多数 Root 管理器还支持开机时按音量键进入安全模式来禁用模块（具体按键请查你所用管理器的说明）。
- 直接刷写的：用 adb 重启到 Fastboot（`adb reboot bootloader`），按下面第 ③ 条刷回备份。

**③ 无法开机 / 卡在开机画面**
进入 Fastboot（通常是关机后按住 **音量下 + 电源**），在电脑上刷回备份：

```bash
# 槽位以救砖备忘录上记录的为准，常见为 dtbo_a 或 dtbo_b
fastboot flash dtbo_a 你的备份文件.img
fastboot reboot
```

或者在 Recovery 里刷之前导出的**救援包 zip**。

> 这就是为什么第 6.3 节反复强调要把备份和救援包**复制到电脑**：手机开不了机的时候，存在手机里的文件拿不出来。

## 9. 常见问题

**Q：刷入后系统设置里没有新刷新率？**
A：部分系统只显示固定几档。可以用第三方工具切换，或改用「编辑修改档位」模式把原来的最高档直接改成目标刷新率。

**Q：显示是 144 Hz，但测出来还是 120 Hz？**
A：可能是命令模式屏（见第 7 节），或者改的不是「本机生效」的 DTB。回去确认 DTB 实例是否带「本机生效」标记。

**Q：选中的档位按钮是灰的，提示“请选择普通档位后继续”？**
A：你选了自动变频档位，换成同一屏幕里名字带 `normal` 的档位。

**Q：没有 Root 能用吗？**
A：能。手动导入 `dtbo.img` → 修改 → 打包 → 导出 Fastboot 一键包或 `dtbo_patched.img`，然后用电脑刷。但无法自动识别在用屏幕，也没有应用内备份，需自己备份原版。

**Q：温控表格子一直是红框？**
A：检查这一档是不是比上一档大了。同一列从上往下，数值只能相等或变小。

**Q：Charging 面板里有很多参数是只读的？**
A：应用只开放单位和含义已经确认的参数，没把握的厂商私有参数一律保持只读，这是为了安全。详见 [Charging 参数说明](charging.md)。

**Q：刷新率和温控可以一起改吗？**
A：可以。两边分别暂存，然后在「概览」一次集中打包、一次刷入。

**Q：系统 OTA 更新后修改还在吗？**
A：OTA 通常会覆盖 DTBO 分区，修改会失效。更新后需要重新提取、重新修改。模块方式刷入的，更新后建议先移除旧模块，再基于新系统的 DTBO 重新制作。
